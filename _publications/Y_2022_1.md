## Abstract

**Objective:**  
This study develops a unified framework combining hybrid principal component analysis (HPCA) with functional regression for the analysis of high-dimensional EEG–fMRI data. The proposed approach reconstructs functional signals using HPCA as a feature extraction step and evaluates predictive performance using functional regression models.

**Methods:**  
The hybrid data structure is decomposed into eigencomponents using HPCA. Reconstructed signals are partitioned into training and testing datasets. Both function-on-function and scalar-on-function regression models are applied to EEG–fMRI data collected from auditory and visual oddball paradigms. Model performance is evaluated using mean squared prediction error (MSPE), and the optimal number of HPCA components is selected based on predictive accuracy.

**Results:**  
Simulation studies demonstrate that reconstruction using the first HPCA component yields the lowest MSPE compared to raw and fully reconstructed representations. In real EEG–fMRI applications, the first HPCA component consistently provides superior predictive performance across auditory and visual tasks, as well as across multiple brain regions and stimulus conditions.

**Conclusion:**  
The results indicate that HPCA-based reconstruction significantly improves predictive performance in functional regression models for EEG–fMRI data. The proposed framework outperforms traditional functional PCA-based approaches in capturing complex neurophysiological patterns.

## Supplementary Material

The supplementary material provides an extended analysis of four EEG–fMRI datasets obtained from 17 participants.

### Dataset Structure

- Auditory oddball task — standard stimuli  
- Auditory oddball task — target stimuli  
- Visual oddball task — standard stimuli  
- Visual oddball task — target stimuli  

In this framework, EEG signals are treated as response functions, while fMRI region-of-interest (ROI) curves based on Brodmann areas are used as functional covariates.

### EEG Region Grouping

- Whole brain  
- Frontal  
- Central  
- Parietal  
- Occipital  
- Right temporal  
- Left temporal  

### Analytical Pipeline

1. Decomposition of EEG signals into functional, longitudinal, and regional components using HPCA  
2. Reconstruction of EEG curves using the first to KLM HPCA components  
3. Function-on-function regression with multiple ROI covariates (train/test split)  
4. Evaluation using correlation and mean squared prediction error (MSPE)  
5. Selection of optimal HPCA components based on MSPE, correlation, and computational efficiency
