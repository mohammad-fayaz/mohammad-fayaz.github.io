## Abstract

**Objective**: This study proposes a framework combining hybrid principal component analysis (HPCA) and functional regression for analyzing complex EEG-fMRI data. The approach reconstructs hybrid data using HPCA as a feature extraction step and applies functional regression models for prediction. Model selection is performed based on prediction accuracy.
**Method**: The hybrid data are decomposed into eigencomponents using HPCA. Reconstructed signals are split into training and testing datasets. Both function-on-function and scalar-on-function regression models are applied. Simulation studies and real EEG-fMRI applications involving auditory and visual tasks are conducted. Model performance is evaluated using mean squared prediction error (MSPE), and the optimal number of HPCA components is selected accordingly.
**Results**: Simulation results show that reconstructed data using the first HPCA component yields the lowest median MSPE compared to raw data and full reconstruction scenarios. In EEG-fMRI applications, the first HPCA consistently provides the best predictive performance across auditory and visual tasks, as well as across different brain regions and stimulus types.
**Conclusion**: The proposed HPCA-based reconstruction combined with functional regression improves prediction accuracy in EEG-fMRI studies. The findings suggest that HPCA-based feature reconstruction is more effective than traditional functional PCA approaches for modeling high-dimensional neuroimaging data.

## Supplementary Material

This supplementary report extends the main article by analyzing four EEG-fMRI datasets collected from 17 participants.

### Dataset Description
- Auditory oddball task — standard stimuli  
- Auditory oddball task — target stimuli  
- Visual oddball task — standard stimuli  
- Visual oddball task — target stimuli  

EEG signals are treated as response functions, while fMRI ROI curves (based on Brodmann areas) are used as functional covariates.

### Brain Region Grouping (EEG electrodes)
- Whole brain  
- Frontal  
- Central  
- Parietal  
- Occipital  
- Right temporal  
- Left temporal  

### Analysis Pipeline
1. Decomposition of EEG into functional, longitudinal, and regional components using HPCA  
2. Reconstruction of EEG curves using first to KLM HPCA components  
3. Function-on-function regression with multiple ROI curves (train/test split)  
4. Evaluation using correlation and mean squared prediction error (MSPE)  
5. Selection of optimal HPCA components based on MSPE, correlation, and computation time
